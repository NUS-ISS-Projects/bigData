🚀 Part 3: One-Command Deployment

⚡The Magic Command

./setup_and_deploy_api.sh

What This Single Command Does:

  • Creates Kubernetes namespace
  • Deploys MinIO S3 storage
  • Sets up Apache Kafka cluster
  • Launches Spark streaming
  • Configures dbt analytics
  • Starts data producers
  • Initializes monitoring

🔄Deployment Flow Sequence

1
Namespace Creation
Creates 'economic-intelligence' namespace and applies RBAC policies
2
Storage Layer Deployment
MinIO S3-compatible storage with persistent volumes and service exposure
3
Message Broker Setup
Apache Kafka cluster with Zookeeper, topics auto-creation, and load balancing
4
Stream Processing Engine
Spark streaming jobs for real-time ETL and Bronze→Silver→Gold transformations
5
Data Producers Launch
5 data producers (ACRA, URA, SingStat, Gov Expenditure) with scheduled ingestion
6
Analytics & Monitoring
dbt models, Streamlit dashboard, and health monitoring services
