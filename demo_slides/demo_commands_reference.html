🚨 Troubleshooting Commands

  • Pod not starting: kubectl describe pod <pod-name> -n economic-observatory
  • Service not accessible: kubectl get svc -n economic-observatory
  • Check logs: kubectl logs <pod-name> -n economic-observatory --tail=50
  • Restart deployment: kubectl rollout restart deployment/<deployment-name> -n economic-observatory
  • Check resource limits: kubectl describe nodes
  • Clean restart: kubectl delete namespace economic-observatory && ./setup_and_deploy_api.sh
